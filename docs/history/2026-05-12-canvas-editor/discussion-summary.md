# 討論紀錄摘要

日期：2026-05-12

## 目標

將右側檢視區從唯讀自動 layout 改為可編輯畫布，支援手動拖拉節點與編輯連線。

## 決策紀錄

| # | 問題 | 決策 |
|---|------|------|
| 1 | 手動 vs 自動混合？ | 一旦進入手動模式，全部手動。所有座標放入 code block |
| 2 | 連線編輯範圍？ | 拖拉路徑 + 新增/刪除連線 + 手動指定 port side |
| 3 | 節點尺寸？連線路由？ | 尺寸由 theme 決定不記錄；連線需記錄彎折點座標 |
| 4 | 即時同步？ | 是，畫布與 markdown 雙向即時同步 |
| 5 | Zone 框？ | 自動根據內含節點位置重新計算 |
| 6 | 重置？ | 提供重置全部 + 重置單一節點 + Ctrl+Z undo |
| 7 | 新增連線 UX？ | 從 port 拖到目標節點後彈表單；刪除用 Delete 鍵 |
| 8 | Code block 格式？ | 純 ` ``` ` 無語言標記 |
| 9 | 進入手動模式？ | 需明確按鈕切換，避免誤觸 |
| 10 | Undo 範圍？ | 畫布 + 文字編輯器共用一個 undo stack |
| 11 | 手動模式下左側可編輯？ | 可以。改名→更新 key、新增→預設位置、刪除→移除條目 |
| 12 | Code block 辨識？ | 靠位置（永遠在文件最末尾） |
| 13 | Port side 記錄？ | 起點/終點皆需記錄 |
| 14 | 畫布新增節點？ | 可以。雙擊空白處建立預設節點，hover 節點顯示連線提示 |
| 15 | 新增節點資訊？ | 先建立預設節點，之後再編輯。Zone 根據放置位置判斷 |
| 16 | 多選？ | 第一版只支援單選拖動 |
